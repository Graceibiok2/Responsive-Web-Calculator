# Responsive-Web-Calculator
 # Responsive JavaScript Calculator

A browser-based calculator built to practice responsive web design and JavaScript logic. The layout automatically scales to fit both mobile screens and desktop monitors.

##  Live Demo
[Launch the Calculator](https://graceibiok2.github.io/Responsive-Web-Calculator/index.html)

## How It Works

### Design & Layout (CSS)
*   **Grid System:** Used CSS Grid to build a perfectly aligned, 4-column button layout.
*   **Fluid Sizing:** Used the `clamp()` function so text and buttons automatically resize to fit smaller phone screens.
*   **CSS Variables:** Set up custom properties (like `--btn-bg` and `--operator-bg`) at the top of the file to manage the theme colors easily.
*   **Visual Effects:** Added active states and hover transitions to make the buttons visually change color when clicked or hovered over.

### Structure & Logic (HTML & JS)
*   **Semantic HTML:** Structured with clean markup and specific element IDs for button tracking.
*   **Vanilla JavaScript:** Programmed the core math logic to read user inputs, calculate results, and update the screen display.

## 📄 How to Run Locally
1. Clone or download this repository.
2. Double-click the `index.html` file to open and use the calculator instantly in any web browser.
